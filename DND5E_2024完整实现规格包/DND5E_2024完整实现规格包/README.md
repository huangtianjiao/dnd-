# D&D 5e 2024 完整实现规格包

审计基线：huangtianjiao/dnd-，master @ 99f4c3499da168a2f447771cfd623916b9666620（2026-07-31）。规则基准：仓库 5echm_web/topics/玩家手册2024、城主指南2024、怪物图鉴2024及项目内结构化规则。

## 这套文档解决什么问题

该仓库已经明确采用2024版，并且拥有相当丰富的原始规则语料、数据表和若干正确的基础函数；但当前实现仍存在“规则文本存在、代码未执行”“引擎函数存在、生产链路绕过”“LLM仍能提供权威数值”三类系统性问题。

本规格包不是简单的Bug列表，而是可直接交给实现型AI分阶段施工的工程契约。它定义：

1. 什么叫“完整实现”；
2. 当前有哪些漏洞和缺口；
3. 应采用怎样的领域架构、状态模型、触发时序和数据DSL；
4. 战斗、施法、角色、物品、怪物、探索应如何实现；
5. 怎样用覆盖清单和自动测试证明完成，而不是凭文档宣称完成。

## “完整实现”的定义

“完整”不等于把规则书文字放进RAG，也不等于为每个规则写一个孤立函数。只有同时满足下列条件才算完成：

- 内容项有稳定ID、版本和原文来源；
- 机械效果有可执行handler或Effect DSL；
- 生产入口真实调用该实现；
- 所有权威数值从状态和规则数据派生，而非LLM猜测；
- 状态变化通过原子、幂等的领域事件提交；
- 至少有规则级单测和生产链路场景测试；
- CoverageManifest标记为FULL且CI门禁通过。

建议把范围分为：PHB2024核心规则（必须100%机械覆盖）、DMG2024运行模块（按功能包逐个完成）、MM2024怪物内容（所有公开怪物动作可执行）。房规、旧版兼容和自定义内容必须使用独立policy/content pack，不能悄悄混入2024 RAW。
