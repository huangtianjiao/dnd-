# DND 5e 规则边界分析报告

> 基于原始规则书（5echm_web 仓库 HTML 文件）与 aidm 代码实现的交叉比对
> 生成日期：2026-07-29

## 概述

本报告对比了 5echm_web 仓库中的 DND 5e 原始规则书内容与 aidm 项目的代码实现，识别出规则边界条件上的差异和潜在问题。

规则书来源：
- 2014版：`topics/玩家手册/` 下的 HTML 文件
- 2024版：`topics/玩家手册2024/` 下的 HTML 文件

---

## 高严重度问题

### 问题 1：天然20/1 被错误地应用于所有 d20 检定

- **位置：** `src/aidm/engine/check.py` — `_d20_check_core` 函数
- **代码当前行为：** `_d20_check_core` 对所有调用它的检定（属性检定、豁免检定）都施加了天然20自动成功、天然1自动失败的逻辑。`ability_check()` 和 `saving_throw()` 都调用了 `_d20_check_core`
- **规则书原文：** 出处 `topics/玩家手册2024/进行游戏/攻击检定.htm`（行60-62）。2024 PHB：天然20和天然1**仅适用于攻击检定**。属性检定和豁免检定的天然20/1无特殊效果，纯比 total vs DC
- **矛盾：** 代码注释（模块文档第4-5行）声明"天然20/1仅对攻击检定生效（R-DM-010）"，但实际实现与注释矛盾
- **修复状态：** ✅ 已修复 — `_d20_check_core` 增加 `auto_success_on_nat20` / `auto_fail_on_nat1` 参数（默认False），`ability_check()` 和 `saving_throw()` 不再触发天然20/1特殊效果，仅死亡豁免传入True。新增4个测试用例覆盖。

## 中严重度问题

### 问题 2：坠入液体检定类型错误

- **位置：** `src/aidm/engine/hazards.py` — `fall_into_liquid_save`
- **代码当前行为：** 使用体质(CON)豁免 (`check.saving_throw`)
- **规则书原文：** 出处 `topics/玩家手册/冒险/环境.htm`。应进行 DC15 的**力量(运动)或敏捷(特技)属性检定**，不是体质豁免
- **影响：** 检定类型和所用属性均错误，角色无法利用力量/敏捷技能熟练加值
- **修复状态：** ✅ 已修复 — 函数重命名为 `fall_into_liquid_check`，改为 `check.ability_check` 属性检定，支持力量(运动)/敏捷(特技)选择，DC15。自检测试已同步更新。

## 中严重度问题

### 问题 3：擒抱/推撞的豁免处理接口不完整

- **位置：** `src/aidm/engine/combat.py` — `attempt_grapple` 和 `attempt_shove`
- **代码当前行为：** 始终将 `proficient=False, prof=0` 传给 `saving_throw`
- **规则书原文：** 出处 `topics/玩家手册/战斗/发起攻击.htm`（行294-331）。目标选择力量(运动)或敏捷(特技)进行对抗检定。如果目标对该技能熟练应加熟练加值
- **影响：** 熟练力量或敏捷的角色可能被错误处理
- **修复状态：** ⚠️ 历史修复方向错误已回滚 — 上述「改为对抗属性检定」依据的是 2014 版玩家手册；本项目基准为 2024 版（`玩家手册2024/术语汇编/武器与徒手打击.htm`）：目标投力量或敏捷**豁免**（由目标选择）对抗 DC = 8 + 攻击者力量调整值 + 熟练加值，并附体型限制（至多大一级）与擒抱需空手。现已按 2024 机制重写（含 `escape_grapple` 逃脱检定），目标豁免熟练通过 `target_save_prof/target_prof` 正确传入。

## 低严重度问题

### 问题 4：躲藏(Hide) DC 允许被覆写

- **位置：** `src/aidm/engine/actions.py` — `action_hide`
- **代码行为：** `dc: int = 15` 作为默认参数，调用方可传入不同值
- **2024规则：** 固定 DC 15（出处：`topics/玩家手册2024/术语汇编/动作.htm` 行84-88）
- **修复状态：** ✅ 已修复 — 新增模块级常量 `HIDE_DC = 15`，从函数签名移除 `dc` 参数，内部使用常量

### 问题 5：邪术师注释措辞误导

- **位置：** `src/aidm/brain/rest.py` — 第399行
- **代码行为：** 注释说"简化"，但实际功能正确
- **修复状态：** ✅ 已修复 — 修正注释措辞，删除"简化"描述，准确说明邪术师法术位恢复机制，同时修正"邪务师"错别字

### 问题 6：仪式施法时间 +10分钟不显式计算

- **位置：** `src/aidm/engine/spellcasting.py`
- **规则：** 仪式施法时间 = 原施法时间 + 10分钟
- **代码：** 由调用方处理时间流逝，函数本身不追踪
- **修复状态：** ✅ 已修复 — 在 `cast_spell` 返回值中新增 `ritual_time_extra` 字段（仪式时600秒，非仪式时0）
