一、D&D 5e 概览与三大支柱

D&D 5e 的游戏建立在三大支柱之上：战斗（Combat）、探索（Exploration）、社交互动（Social Interaction）。一场典型的会话（Session）会在三种模式之间反复切换，但无论当前处于哪种模式，底层引擎都是同一个——核心游戏循环。

⚔️ 战斗
结构化回合制

先攻序列 → 每人一个回合 → 6秒一轮 → 直到一方被消灭/逃跑/投降

🧭 探索
半结构化

旅行步调 → 感知检定 → 搜索房间 → 资源消耗 → 随机遭遇

💬 社交
自由叙事

玩家扮演对话 → DM 扮演 NPC → 需要时掷魅力检定 → 结果推动剧情

💡 核心设计理念

D&D 5e 的"有界精度"（Bounded Accuracy）设计意味着：即使低等级角色，在有利条件下也有可能成功；即使高等级角色，也不是自动成功。这使得掷骰始终有意义，DM 的 DC 设置始终有张力。

二、第一阶段：Session 0（游戏前准备）

Session 0 是正式游戏前的准备会议，通常持续 1-3 小时。这不是角色创建会——虽然角色创建经常在这里发生。它的本质是期望校准与社交契约。

Session 0 标准流程

1

基调与类型校准

DM DM 描述战役的预期风格（黑暗写实 / 高魔奇幻 / 政治阴谋 / 恐怖风格）

玩家 玩家确认是否符合自己的期望

双方 在 1-10 的尺度上对齐"严肃剧情"到"随性搞笑"的位置

2

内容边界（Lines and Veils）

双方 建立"线"（Lines）——完全不会出现在游戏中的话题

双方 建立"纱"（Veils）——可以存在但不会详细描写的话题

双方 确认 X-Card 机制——任何人可以随时举牌叫停

3

规则与后勤

DM 说明使用的规则版本（2014 PHB / 2024 修订版）和房规

DM 确认升级方式：经验值（XP）还是里程碑（Milestone）

双方 确认会话频率、时长、缺席处理方式

DM 说明角色死亡的处理方式（复活魔法是否容易获取等）

4

角色创建与队伍凝聚

玩家 创建角色，互相了解彼此的概念

双方 建立角色之间的关系——避免"五个互不认识的独狼"问题

DM 介绍起始地点，让玩家将背景故事编织进世界

5

Session 0.5（可选）

DM 运行一个低风险的迷你遭遇，让玩家熟悉机制

玩家 测试角色能力，感受战斗节奏

以悬念结尾，让玩家期待 Session 1

三、第二阶段：角色创建流程

角色创建遵循明确的步骤顺序，每一步都会影响后续选择：

1

选择职业（Class）

最重要的决定——决定战斗角色、施法能力、生命骰和升级路线。12个核心职业：战士(d10)、法师(d6)、牧师(d8)、游荡者(d8)、吟游诗人(d8)、野蛮人(d12)、德鲁伊(d8)、圣武士(d10)、游侠(d10)、术士(d6)、邪术师(d8)、武僧(d8)。

2

选择种族（Race）

提供属性加成、特殊能力和语言。Tasha's 规则后，属性加成可自由分配。

3

决定属性值（Ability Scores）

六项属性：力量(STR)、敏捷(DEX)、体质(CON)、智力(INT)、感知(WIS)、魅力(CHA)。三种生成方式：

  • 标准阵列：15, 14, 13, 12, 10, 8 —— 可靠均衡
  • 点数购买：27点，单属性最高15（种族加成前）—— 最平衡
  • 掷骰：4d6 弃最低，重复6次 —— 波动大但可能很强

属性调整值 = (属性值 - 10) / 2，向下取整。例如 16 → +3

4

选择背景（Background）

提供2个技能熟练度、2个工具或语言、装备和角色扮演基础。如：士兵、学者、罪犯、平民英雄。

5

选择技能与装备

职业提供2-4个技能选择，背景再给2个。选择起始装备包（通常比等价金币更优）。

6

选择法术（如适用）

施法者选择起始法术和戏法。建议搭配：一个伤害戏法 + 一个控制法术 + 一个辅助法术。

7

计算衍生数值

  • 生命值：1级 = 职业生命骰最大值 + CON调整值
  • 护甲等级（AC）：10 + DEX调整值（无甲）/ 取决于护甲类型
  • 先攻：d20 + DEX调整值
  • 熟练加值：1级时为 +2，每4级提升
  • 被动感知：10 + 感知(察觉)熟练加值
8

角色扮演细节

选择阵营、性格特质、理想、羁绊、缺陷。这些让角色从数据表变成活生生的人。

四、核心游戏循环：描述-行动-解决

无论在战斗、探索还是社交中，D&D 5e 的底层引擎始终是同一个三步循环。这个循环不断重复，构成了整个游戏的节奏。

核心循环三步

A

DM 描述环境

DM DM 描述角色当前所处的环境、正在发生的事件、NPC 的行为。范围可大可小——从世界级的地缘政治格局，到角色眼前一扇锁着的门。

B

玩家描述行动

玩家 玩家用自然语言描述自己的角色想做什么。不需要说"我掷察觉检定"——只需要说"我把耳朵贴在门上听里面的声音"。由 DM 决定是否需要掷骰。

C

DM 解决结果并叙述

DM DM 判断行动结果：

  • 确定无疑（走穿过房间）→ 直接叙述结果，不掷骰
  • 结果不确定（撬锁、攀爬悬崖）→ DM 要求掷骰
  • 不可能（凡人跳过峡谷）→ 直接叙述失败，不掷骰

如果需要掷骰：DM 设定 DC（难度等级）→ 玩家掷 d20 + 修正值 → 总数 ≥ DC 则成功。

循环回到步骤 A，DM 描述新的环境状态。

掷骰公式

d20 + 属性调整值 + 熟练加值（如适用） ≥ DC（难度等级） → 成功

d20 + 属性调整值 + 熟练加值（如适用） < DC（难度等级） → 失败

DC 值难度示例
5非常简单跟踪泥地中的明显脚印
10简单攀爬有充足手抓点的岩壁
15中等撬开一把普通门锁
20困难在激流中游泳
25非常困难在暴风雪中导航
30几乎不可能徒手掰弯铁栅栏

三种 d20 检定

能力检定

玩家主动做有失败风险的事。如：力量(运动)攀爬、敏捷(隐匿)潜行、魅力(说服)交涉。

d20 + 属性调整值 + 熟练加值 ≥ DC

攻击检定

攻击敌人时。如：近战武器攻击用STR/DEX，法术攻击用施法属性。

d20 + 攻击加值 ≥ 目标 AC（护甲等级）

豁免检定

被动反应危险。如：敏捷豁免躲火球、体质豁免抗毒素、智慧豁免抗精神控制。

d20 + 属性调整值 + 熟练加值 ≥ 法术DC/效果DC

⚡ 关键规则：只有 DM 能要求掷骰

玩家不应该主动说"我掷说服"。正确流程是：玩家描述行动 → DM 判断是否需要掷骰 → DM 说"请做一个魅力(说服)检定"。如果玩家主动要求掷骰，DM 应该问"你想做什么？"，把对话拉回正轨。

🎲 自然1与自然20

攻击检定中：自然1（骰面为1）= 自动未命中；自然20（骰面为20）= 自动命中且暴击（伤害骰翻倍）。能力检定中：5e 原始规则中，自然1和20只在攻击检定中有特殊效果——但许多 DM 会给能力检定的自然20加上"特别好"的叙事效果。

五、战斗流程：从掷先攻到回合结束

战斗是 D&D 5e 中最结构化的部分。当战斗爆发时，游戏从自由叙事切换到严格的回合制。

战斗遭遇启动流程

1

判定突袭（Determine Surprise）

DM DM 判断是否有任何一方被突袭。突袭不是单独的轮次——它是一个状态。被突袭的生物在自己的第一个回合中不能移动、不能执行动作、不能使用反应。

DM 通常基于隐匿检定 vs 被动感知来判定。被突袭者仍然掷先攻，只是在第一轮无法行动。

2

确定位置（Establish Positions）

DM DM 确定所有角色和怪物的起始位置——基于行进方向、房间布局和距离。在网格地图上放置棋子或标记。

3

掷先攻（Roll Initiative）

玩家 每位玩家为自己的角色掷先攻：d20 + DEX调整值

DM DM 为每组相同怪物掷一次先攻（或为每只怪物单独掷）

DM 将所有结果从高到低排列，形成先攻序列。这个序列在整个战斗中保持不变。

双方 平局处理：同为DM控制则DM决定顺序；同为玩家则玩家自行决定；DM角色与玩家平手则DM决定。

4

执行回合（Take Turns）

双方 按先攻顺序，每人执行一个回合。一轮（Round）= 游戏世界6秒，所有参战者各行动一次。

5

开始新一轮（Begin Next Round）

双方 所有人完成回合后，回到先攻序列顶端，开始新一轮。重复步骤4直到战斗结束。

单个回合的详细结构

在你的回合里，你可以做以下事情（顺序自选）：

回合内行动选项

① 移动（Movement）

玩家 角色可以移动至多等于其速度的距离（通常30尺）。移动可以拆分——先移动10尺，攻击，再移动20尺。

  • 穿越敌人位置：友方可以穿过；敌方位置不能穿越（需要绕行）
  • 离开敌人触及范围：引发借机攻击（见下方反应）
  • 困难地形：每尺消耗2尺移动力
  • 攀爬/游泳：每尺消耗2尺移动力
  • 跳跃：基于力量值决定距离，消耗正常移动力

② 动作（Action）—— 每回合一个

动作效果
攻击发动一次武器攻击或徒手攻击（高等级战士可攻击多次）
施法施放一个施法时间为1动作的法术
冲刺移动力翻倍（本回合）
脱离本回合剩余移动不引发借机攻击
闪避到下回合开始前，对你的攻击检定具有劣势，你的敏捷豁免具有优势
协助盟友下次攻击该目标具有优势，或协助完成一项能力检定
躲藏进行敏捷(隐匿)检定，成功则对敌人隐藏
预备设定一个触发条件，使用反应在条件满足时执行动作
搜索进行感知(察觉)或智力(调查)检定
使用物品使用一个物品或工具（如开锁器、治疗药水）

③ 附赠动作（Bonus Action）—— 仅当有资格时

玩家 只有当特定职业特性、法术或能力允许时，才能执行附赠动作。每回合最多一个。常见来源：

  • 游荡者的灵巧动作（附赠动作：疾走/脱离/躲藏）
  • 野蛮人的狂暴（附赠动作：进入狂暴）
  • 吟游诗人的吟游灵感（附赠动作：给予盟友灵感骰）
  • 施法时间为附赠动作的法术（如治疗真言）

④ 免费物品互动（Free Object Interaction）

玩家 每回合可以免费与一个物品互动——拔剑、开门、从鞘中抽出匕首。额外的物品互动需要消耗"使用物品"动作。

⑤ 对话（Free Speech）

玩家 可以在回合中说几句话——6秒内能说的量。不需要消耗动作。

反应（Reaction）—— 不在你的回合也能行动

每轮你有一个反应，在你的下一回合开始时恢复。反应可以在任何人（包括你自己）的回合使用：

  • 借机攻击（Opportunity Attack）：当一个敌对生物移出你的触及范围时，你可以用反应对它进行一次近战攻击
  • 预备动作触发：当你之前用动作预备了一个动作并设定了触发条件时
  • 特定法术：如护盾术（被攻击时反应施放，+5 AC）、反击术（敌人在你范围内施法时）、羽落术（坠落时）

一次完整攻击的交互流程

// 战斗中，轮到战士玩家A的回合 DM: 战士，轮到你了。地精在你前方15尺，你面前没有障碍。 玩家A: 我冲向地精，用长剑砍它！ // 步骤1: 玩家移动15尺到地精面前（消耗15尺移动力） // 步骤2: 玩家声明用动作进行攻击 DM: 好的，你移动到它面前。请做一个攻击检定。 // 步骤3: 玩家掷攻击检定 = d20 + STR(+3) + 熟练加值(+2) 玩家A: （掷骰） 我掷出了……14。加上5，总共19。 // 步骤4: DM将总数与地精的AC比较 DM: （地精AC是15，19 ≥ 15 → 命中！） 你的剑砍中了地精！掷伤害吧。 // 步骤5: 玩家掷伤害 = 武器伤害骰 + STR调整值 玩家A: （掷骰） 长剑伤害1d8……掷出6，加上力量加值3，总共9点伤害。 DM: （地精剩余HP: 7 - 9 = -2 → 死亡） 你的长剑深深劈入地精，它惨叫一声倒地不起。你还剩15尺移动力，要移动吗？ 玩家A: 不用了，我站在这里警戒其他敌人。 // 回合结束，先攻序列进入下一个参战者

六、探索流程：旅行、地城与资源管理

探索是三大支柱中最被忽视、却占用最多实际游戏时间的部分。它涵盖了旅行、地城导航、陷阱检测、资源管理等一系列互锁机制。

旅行探索流程

1

设定旅行步调

玩家 队伍选择一个旅行步调：

步调速度效果
快速30里/日被动感知 -5（更容易被伏击）
正常24里/日无修正
慢速18里/日可以隐身行进、可以觅食
2

分配队伍职责

玩家 分配角色：导航员（负责找路）、侦察兵（负责前方警戒）、后卫（负责殿后）、军需官（负责补给）。

3

导航检定

DM DM 根据地形设定导航 DC（森林 DC 15，沼泽 DC 15，无地标海域 DC 20）

玩家 导航员进行感知(生存)检定

DM 失败则队伍偏离路线——可能多走一天，也可能闯入危险区域

4

被动感知与遭遇检测

DM DM 用敌人的隐匿检定对比队伍的被动感知（10 + 感知(察觉)修正值）

如果敌人隐匿 > 队伍被动感知 → 队伍被伏击（突袭！）

如果敌人隐匿 ≤ 队伍被动感知 → 队伍提前发现敌人，可以准备

5

随机遭遇检定

DM DM 定期掷随机遭遇骰（通常每日2次，d20 ≥ 18 触发）

遭遇不一定是战斗——可能是环境事件、文明痕迹、生物足迹

6

资源追踪

双方 每日消耗口粮（每生物1磅）、追踪水源、火把持续时间（每根1小时）、黑暗视觉范围（60尺）

缺乏食物/水/睡眠 → 累力等级累积（6级制，1级劣势能力检定，6级死亡）

地城探索流程

地城探索使用更紧凑的时间单位——通常以10分钟为一段（探索回合）：

// 地城探索的典型交互 DM: 你们沿着走廊走了约60尺，来到一扇石门前。门看起来很厚实，没有明显的锁孔。 玩家A: 我把耳朵贴在门上听里面有没有声音。 // DM判断: 这有失败的可能（门厚、隔音好）→ 需要掷骰 DM: 好的，请做一个感知(察觉)检定。DC我来定。 玩家A: （掷骰） 15 + 3 = 18。 DM: （DC 15，成功） 你隐约听到门后有低沉的吟唱声，像是某种仪式。声音断断续续，至少有两个声音。 玩家B: 我检查门上有没有陷阱。 DM: 请做一个智力(调查)检定，或者感知(察觉)检定——你想怎么检查？ 玩家B: 我仔细摸门的边缘和门把手，找有没有机关。 DM: 那是智力(调查)。请掷骰。 玩家B: （掷骰） 呃……4 + 2 = 6。 DM: （DC 13，失败） 你仔细摸索了门边，没发现任何异常。（实际上门把手有一个毒针陷阱，但你没找到） A: 我推开门！ DM: （触发陷阱！门把手毒针攻击） 当你抓住门把手时，一根细小的针刺入了你的手掌……请做一个敏捷豁免检定。 玩家A: （掷骰） 11 + 2 = 13。 DM: （陷阱DC 12，成功 → 半伤害） 你在最后一刻缩回了手，但还是被针尖划过。受到1d4/2 = 2点毒素伤害，并且需要进行体质豁免对抗毒素效果…… // 以上整个交互大约消耗了10分钟的游戏内时间
🔍 被动感知 vs 主动检定

DM 用被动感知决定角色是否"自动"注意到某些东西——不需要玩家要求掷骰。例如：队伍被动感知最高的人为16，走廊里有一个 DC 15 的秘密门 → 最高被动感知者自动注意到墙上有异常缝隙。但如果 DC 是18，则需要玩家主动说"我搜索墙壁"并掷骰才能发现。

七、社交互动流程

社交互动是三大支柱中规则约束最少、自由度最高的部分。大部分社交通过角色扮演对话完成，只在结果不确定时才掷骰。

社交互动循环

1

DM 扮演 NPC

DM DM 以 NPC 的口吻说话，描述 NPC 的表情、姿态、语气。NPC 有自己的目标、态度和知识——DM 扮演他们就像扮演另一个角色。

2

玩家角色扮演回应

玩家 玩家以自己角色的口吻回应，描述自己说的话和做的动作。重要的是描述意图和方法，而不是说"我掷说服"。

好的说法："我走近守卫，压低声音说：'如果你放我们进去，没人需要知道你见过我们。'"

不好的说法："我掷说服检定。"

3

DM 判断是否需要掷骰

DM DM 评估：

  • NPC 是否可能被说服/欺骗/恐吓？→ 如果角色扮演足够好，可能自动成功
  • 结果是否不确定？→ 需要掷骰
  • NPC 的态度（友善/中立/敌对）影响 DC
4

掷骰与解决

玩家 掷相应技能检定：

  • 说服（Persuasion）：魅力检定，真诚影响他人态度
  • 欺瞒（Deception）：魅力检定，说谎或误导
  • 威吓（Intimidation）：魅力检定，用威胁迫使合作
  • 表演（Performance）：魅力检定，娱乐或伪装
  • 洞悉（Insight）：感知检定，判断 NPC 是否说谎

DM DM 秘密设定 DC，比较结果，叙述 NPC 的反应和对话。

⚠️ 说服不是精神控制

说服检定成功不会让 NPC 做完全不合理的事。你不能用说服让酒馆老板免费让你住3个月——这不叫说服，这叫妄想。DC 30 的任务几乎是"不可能"级别的。如果 NPC 根本不可能同意，DM 应该直接说"不，这不可能"，不需要掷骰。

八、施法流程详解

施法是 D&D 5e 中最复杂的子系统之一，但遵循固定的流程：

施法步骤

1

声明施法

玩家 在自己的回合声明要施放哪个法术，使用什么等级的法术位（可升环施放）。

2

确认施法时间

大多数法术施法时间为1动作。部分为附赠动作（如治疗真言）、反应（如护盾术）、或更长时间（仪式施法+10分钟）。

⚠️ 附赠动作施法限制

如果你用附赠动作施放了一个法术，你这回合不能再施放其他法术——除非是施法时间为1动作的戏法（Cantrip）。

3

确认法术成分

检查法术是否需要：

  • 言语（V）：需要能说话——被塞嘴或沉默术中无法施法
  • 姿势（S）：需要至少一只手自由——被绑缚无法施法
  • 材料（M）：需要法术焦点或材料包（除非有花费的材料需单独购买）
4

解决法术效果

法术效果有三种解决方式：

攻击检定型

如火焰箭、魔法飞弹攻击

d20 + 法术攻击加值 ≥ 目标AC

命中 → 掷伤害

豁免检定型

如火球术、人类定身术

法术DC = 8 + 熟练加值 + 施法属性调整值

目标掷豁免 → 失败受全效/成功受半效

自动生效型

如魔法飞弹、护盾术、治疗真言

不需要攻击检定或豁免检定

直接产生效果

5

消耗法术位

玩家 消耗对应等级的法术位。戏法（0环）不消耗法术位，可以随意施放。长休恢复所有法术位（邪术师在短休恢复）。

6

维持集中（如需要）

标注"集中"的法术需要施法者保持集中。规则：

  • 同时只能集中维持一个法术——施放新的集中法术，旧的立刻结束
  • 可以随时主动放弃集中（不需要动作）
  • 受到伤害时 → 体质豁免 DC = 10 或伤害值的一半（取较高）→ 失败则法术中断
  • 被失能或死亡 → 自动中断集中

施法公式速查

项目公式
法术攻击加值熟练加值 + 施法属性调整值
法术豁免DC8 + 熟练加值 + 施法属性调整值
法师智力 (INT)
牧师/德鲁伊/游侠感知 (WIS)
吟游诗人/术士/邪术师/圣武士魅力 (CHA)

九、休息机制：短休与长休

休息是资源管理的核心。冒险者何时休息、能否安全休息，直接决定了冒险的节奏和难度。

🟢 短休（Short Rest）

时长：至少1小时，进行轻度活动（吃、喝、阅读、包扎伤口）

恢复内容：

  • 花费生命骰恢复HP——每枚生命骰掷骰 + CON调整值 = 恢复量
  • 邪术师恢复所有法术位
  • 战士恢复行动涌动和风之息
  • 武僧恢复所有真气点
  • 吟游诗人(5级+)恢复吟游灵感
  • 德鲁伊恢复野性变身

限制：无每日上限，但实际地城时间通常不允许频繁短休

🟣 长休（Long Rest）

时长：至少8小时，其中至少6小时睡眠（精灵需4小时出神），最多2小时轻度活动（站岗、阅读）

恢复内容：

  • 恢复所有HP
  • 恢复已花费生命骰的一半（向下取整，至少1枚）
  • 恢复所有法术位（除邪术师外的施法者）
  • 恢复几乎所有职业特性
  • 重置所有"长休后恢复"的特性

限制：每24小时最多获益一次；开始长休时至少有1HP；被战斗打断需重新开始8小时

🎯 休息的战略意义

不同职业对休息的依赖不同：邪术师和战士依赖短休恢复资源，如果 DM 从不给短休机会，这些职业会被暗中削弱。法师和牧师依赖长休恢复法术位。一个冒险日（两次长休之间）中安排几次短休、多少次战斗，直接决定了队伍的资源消耗节奏和战斗难度。

十、濒死与死亡流程

当角色 HP 降至 0 时，进入濒死状态。这是 D&D 5e 中最紧张的机制之一。

HP 归零后的流程

1

判定是否瞬间死亡

DM 如果受到的伤害将角色降至0HP 且剩余伤害 ≥ 角色最大HP → 瞬间死亡，无法挽救。

例：角色最大HP 15，当前HP 6，受到 21 点伤害 → 降至0后剩余15 ≥ 15 → 瞬间死亡。

如果剩余伤害 < 最大HP → 角色倒下，进入濒死状态。

2

濒死状态（0 HP, Unconscious）

角色倒地昏迷，无法移动或行动。每轮在你的回合开始时，必须进行死亡豁免检定：

  • 掷 d20，不加任何修正值（除非有特定特性加成）
  • 10+：成功 → 记录1次成功
  • 9以下：失败 → 记录1次失败
  • 自然1（骰面1）：2次失败
  • 自然20（骰面20）：恢复1HP，苏醒！
  • 累计3次成功 → 稳定（不再需要掷骰，但仍昏迷）
  • 累计3次失败 → 死亡
  • 成功和失败不需要连续——各自累积，先到3个为准
3

濒死状态下受到伤害

DM 如果昏迷角色受到任何伤害 → 1次死亡豁免失败

如果是近战暴击（5尺内的攻击对昏迷目标自动暴击）→ 2次失败

如果伤害 ≥ 最大HP → 瞬间死亡

4

挽救濒死角色

有几种方式可以挽救濒死角色：

  • 治疗法术：任何治疗（如治疗真言、治疗伤势、治疗药水）→ 恢复至少1HP → 立刻苏醒，死亡豁免计数归零
  • 医药检定：动作进行 DC 10 感知(医药)检定 → 成功则稳定（不再掷死亡豁免，但仍昏迷，1d4小时后恢复1HP）
  • 医疗包：消耗1次使用次数，自动稳定，不需要检定
  • 濒死之触戏法：接触范围，动作，自动稳定
5

死亡与复活

如果角色真正死亡（3次失败或瞬间死亡），可以通过高等级法术复活：

  • 复生术（Revivify）：3环，300gp钻石，死后1分钟内，恢复1HP
  • 死者复生（Raise Dead）：5环，500gp钻石，死后10天内
  • 完全复生（Resurrection）：7环，1000gp钻石，死后100年内
  • 真实复生（True Resurrection）：9环，25000gp钻石，死后200年内，甚至不需要尸体

十一、完整会话流程示例

下面展示一场典型的3-4小时 D&D 5e 会话的完整流程，标注每个阶段的 DM/玩家交互：

1

开场回顾（5-10分钟）

DM "上次你们在黑潮洞穴深处发现了一扇刻有古代符文的铁门，战士差点被陷阱毒针刺中。你们站在门前，准备下一步行动。"

玩家 回顾上一轮的状态、HP、法术位消耗

2

探索阶段（30-60分钟）

DM 描述当前环境（走廊、房间、气味、声音）

玩家 声明行动："我检查门上有没有陷阱" / "我用法术侦测魔法" / "我推开门"

DM 判断是否需要掷骰 → 玩家掷骰 → DM 叙述结果

循环重复，推进地城探索。消耗时间、法术位、HP

3

社交阶段（15-30分钟）

DM 遭遇 NPC，以 NPC 口吻说话

玩家 角色扮演对话，尝试获取信息、谈判、威胁

DM 需要时要求魅力(说服/欺瞒/威吓)或感知(洞悉)检定

4

战斗阶段（30-90分钟）

DM "从阴影中跳出三只地精！掷先攻！"

玩家 每人掷 d20 + DEX → 排列先攻序列

DM 为地精掷先攻 → 排入序列 → 按顺序执行回合

每人回合：移动 → 动作（攻击/施法）→ 附赠动作（如有）→ DM 叙述结果

循环至战斗结束（一方全灭/逃跑/投降）

5

休息与恢复（10-20分钟）

玩家 "我们需要短休，花生命骰回血"

DM 判断环境是否安全 → 玩家掷生命骰恢复HP → 恢复短休特性

如果时间允许且安全 → 长休8小时 → 全恢复

6

继续探索/战斗（重复2-5）

在会话中多次切换探索→社交→战斗→休息的循环

7

会话结尾与悬念（5-10分钟）

DM 在一个自然的叙事节点暂停——可能是刚打败BOSS后发现新线索，或到达一个令人震惊的场景

DM "你们打败了地精酋长，在他身上找到了一张泛黄的地图，上面标记着地城更深处的一个位置……"

双方 记录当前状态（HP、法术位、物品），约定下次会话时间

8

升级（如触发）

DM 宣布获得经验值或达到里程碑

玩家 升级流程：增加HP（掷生命骰 + CON）、可能获得新特性/法术位/熟练加值提升、选择新法术（如适用）
